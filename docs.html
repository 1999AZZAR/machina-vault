[ 2. EMBED SERVICE INTERFACE ]

Embed horological specimens directly via iframe. The vault automatically strips non-essential UI chrome and centers the vector drafting plate inside the 3:2 viewport. 

<iframe src="https://machina-vault.glassgallery.my.id/?mode=embed&w=3&h=2&seed=Chronometer-Detent&palette=vellum"
        width="600" height="400" frameborder="0"
        style="border:none; aspect-ratio:3/2; width:100%;"
        loading="lazy"></iframe>

Query Parameters

Parameter Type Default Description
mode string workspace Set to embed for isolated 3:2 specimen rendering.
seed / narrative string random Alphanumeric seed string driving the deterministic PRNG.
palette string vellum vellum, blueprint, obsidian, sepia, patina.
w / h number 3 / 2 Width and height proportion (e.g. w=3&h=2).
id string - Reconstructs exact specimen from identifier (e.g. MCV-TOR-AU0TC9).

[ 3. JAVASCRIPT PROGRAMMATIC API ]

Include js/machinadraw.js in browser or Node.js environments: 

const MachinaDraw = require('./js/machinadraw.js');

const result = MachinaDraw.synthesize("Breguet-Tourbillon", {
  width: 600,
  height: 400,
  palette: "blueprint"
});

console.log(result.id);        // "MCV-TOR-XXXXXX"
console.log(result.archetype); // "tourbillon"
console.log(result.metrics);   // { calibre: "CALIBRE GG-492F", frequency: "21,600 A/h", ... }
console.log(result.svg);       // Raw SVG XML string
